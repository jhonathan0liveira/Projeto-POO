# Plano de Testes — Projeto RPG Medieval 2D

## 1. Identificação

- **Projeto:** RPG
- **Cargo:** Engenheiro de QA / Testes
- **Responsável:** Felipe Veloso

## 2. Objetivo

Garantir a qualidade do software por meio da execução de testes, identificação de falhas, validação de correções e desenvolvimento de testes automatizados.

## 3. Escopo dos testes

Serão verificadas as seguintes funcionalidades:

- Gestão de personagens.
- Gerenciamento de monstros.
- Gerenciamento de inventário e equipamentos.
- Gerenciamento de habilidades e magias.
- Gestão de missões e objetivos.

## 4. Tipos de testes

- **Testes funcionais:** verificar se as funcionalidades executam corretamente.
- **Testes de validação:** verificar se os dados inválidos são tratados adequadamente.
- **Testes de persistência:** verificar se os dados são armazenados e recuperados corretamente.
- **Testes de integração:** verificar se diferentes componentes funcionam corretamente em conjunto.
- **Testes de regressão:** verificar se correções não introduziram novos problemas.
- **Testes automatizados:** executar verificações por meio de código.

## 5. Registro de problemas

Os problemas encontrados serão documentados contendo:

- Identificação do problema.
- Funcionalidade afetada.
- Descrição da falha.
- Passos para reprodução.
- Resultado esperado.
- Resultado obtido.
- Status da correção.

## 6. Organização

Os casos de teste, relatórios de problemas, evidências e testes automatizados serão armazenados na pasta `QA` do repositório.
