# BUG-002 — Cache não atualizado ao excluir habilidade usando outra instância

**Funcionalidade:** Exclusão de habilidades

**Classe:** `HabilidadeRepository.java`

**Método:** `delete(Habilidade habilidade)`

**Classe de teste:** `HabilidadeRepositoryTest.java`

**Descrição:**

Ao excluir uma habilidade utilizando uma instância diferente daquela armazenada na lista interna, o registro é removido do banco de dados, mas permanece no cache do repositório.

**Passos para reprodução:**

1. Criar uma habilidade.
2. Consultar a habilidade pelo ID usando `loadFromId()`.
3. Executar `delete()` passando a instância original.
4. Verificar a lista retornada por `getLoadedHabilidades()`.

**Resultado esperado:** A habilidade deve ser removida do banco e do cache, independentemente da instância utilizada na exclusão.

**Resultado obtido:** A habilidade é removida do banco, mas permanece na lista interna.

**Evidências do teste:**

O problema foi reproduzido por meio da classe `HabilidadeRepositoryTest.java`.

Verificações aprovadas:
```text
Aprovado: Consulta para teste de exclusão
Aprovado: Instâncias diferentes do mesmo registro
```

Verificação que apresentou falha:
```text
Exception in thread "main" java.lang.AssertionError: Falha: Remoção do registro do cache por ID
    at HabilidadeRepositoryTest.verificar(HabilidadeRepositoryTest.java:36)
    at HabilidadeRepositoryTest.testarExclusaoComInstanciasDiferentes(HabilidadeRepositoryTest.java:101)
    at HabilidadeRepositoryTest.main(HabilidadeRepositoryTest.java:10)
```

**Status:** Reproduzido — aguardando correção.

**Observação:** O problema ocorre porque a classe `Habilidade` não sobrescreve `equals()`, fazendo com que a remoção da lista dependa da identidade do objeto.
