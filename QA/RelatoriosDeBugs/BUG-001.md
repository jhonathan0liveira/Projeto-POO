# BUG-001 — Jogador pode possuir dinheiro negativo

**Funcionalidade:** Gerenciamento de dinheiro do jogador

**Classe:** `Player.java`

**Método:** `setDinheiro(double dinheiro)`

**Descrição:** O método permite atribuir valores negativos ao dinheiro do jogador, sem realizar qualquer validação.

**Passos para reprodução:**
1. Criar um objeto `Player`.
2. Executar `player.setDinheiro(-100)`.
3. Consultar o valor com `player.getDinheiro()`.

**Resultado esperado:** O jogador não deve possuir dinheiro negativo.

**Resultado obtido:** O método aceita e armazena o valor negativo.

**Status:** Pendente de avaliação.

**Observação:** O líder informou que o dinheiro pode ser removido do escopo do jogo. Caso isso aconteça, este registro poderá ser descartado como não aplicável.
